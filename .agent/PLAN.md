> TL;DR: CONTEXT.md 요건을 유저 스토리와 acceptance로 풀고, 마일스톤 M0~M5 순서로 진행한다.
> 각 마일스톤의 acceptance가 TASKS.md의 acceptance 기준이 된다.

## 유저 스토리

### 인증
- US-01 사용자는 구글/네이버/카카오 버튼 하나로 로그인한다. 가입 절차가 따로 없다.
- US-02 앱을 완전히 종료했다가 다시 열어도 30일 안에는 로그인 상태다.
- US-03 로그아웃하면 즉시 모든 기기에서 refresh 토큰이 무효화된다.

### 채팅방
- US-10 로그인하면 바로 대화를 시작할 수 있는 빈 화면이 나온다. 방을 "만들기" 버튼으로 만들 필요가 없다.
- US-11 첫 메시지를 보내면 방이 사이드바 목록에 생기고 제목이 자동으로 붙는다.
- US-12 사이드바에서 이전 방을 눌러 이어서 대화할 수 있다. 이전 메시지가 전부 보인다.
- US-13 방 제목을 바꾸거나 방을 삭제할 수 있다.

### 대화
- US-20 메시지를 보내면 응답이 글자 단위로 흘러나온다(스트리밍).
- US-21 응답이 오는 동안 같은 방에서 다시 보낼 수 없다.
- US-22 AI는 어드민이 정한 페르소나(말투·성격)로 답한다.

### 음성
- US-30 각 메시지에 "듣기" 버튼이 있어 AI 답변을 음성으로 들을 수 있다.
- US-31 마이크 버튼을 누르고 말하면 텍스트로 변환되어 메시지로 전송된다.
- US-32 보이스 모드를 켜면 말하기 → 답변 듣기 → 다시 말하기가 자동으로 반복된다.
- US-33 음성으로 한 대화도 방에 텍스트로 남고, 음성 입력이었다는 표시가 있다.

### 어드민
- US-40 관리자는 페르소나(시스템 프롬프트)를 편집하고 활성화한다.
- US-41 관리자는 회원 목록과 상태(활성/정지)를 관리한다.
- US-42 관리자는 방/메시지 수, 토큰 사용량을 본다.
- US-43 관리자는 특정 회원의 방과 메시지를 조회할 수 있다(운영 대응).

## 마일스톤

### M0 스캐폴드 · CI/CD 뼈대 — ✅ 완료 (2026-09-13)
- 레포 구조, compose(운영/로컬), nginx, Dockerfile, GH Actions, `.agent/` 워크플로 파일.

### M1 프로젝트 초기화 · 인증
- web: Next.js 초기화(standalone, Vitest, Serwist), `lib/api.ts`, 로그인 페이지, `middleware.ts`.
- api: Spring Boot 초기화(MyBatis, Flyway, JUnit), OAuth2 3사, JWT 쿠키, `/auth/me|refresh|logout`.
- db: SCHEMA.md 확정 → `01-schema.sql` + `V1__init.sql`.
- acceptance:
  - 3사 각각 로그인 후 `/auth/me`가 사용자 정보를 반환한다.
  - 브라우저 종료 후 재접속 시 access 만료 상태에서도 `/auth/refresh`로 자동 복구된다.
  - 로그아웃 후 이전 refresh 쿠키로 `/auth/refresh` 호출 시 401.
  - 같은 이메일로 다른 공급자 로그인 시 정책(D-003 보완 예정)대로 동작한다.

### M2 텍스트 채팅 · SSE
- api: rooms CRUD, `POST /rooms/{id}/messages` SSE, OmniRouteClient, 컨텍스트 윈도우, 페르소나 조회.
- web: 채팅 셸(사이드바+메인), draft 방, 메시지 목록, 스트리밍 말풍선, 409 처리.
- acceptance:
  - 첫 메시지 전송 시 방이 생성되고 사이드바에 즉시 나타난다.
  - 응답이 `delta` 이벤트 단위로 도착하고 `done` 후 새로고침해도 메시지가 남아 있다.
  - 응답 중 재전송 → 409, UI는 전송 버튼 비활성.
  - 메시지 40개 이상인 방에서 LLM 요청 본문에 최근 30개만 포함된다(로그/테스트로 확인).
  - nginx 경유(compose)에서도 스트리밍이 끊기지 않는다.

### M3 음성
- api: `SttProvider`/`TtsProvider` + openai 구현, `/speech/stt`, `/speech/tts`, tmpfs 처리.
- web: `useRecorder`, 듣기/말하기 버튼, 보이스 모드 오버레이 + 자동 루프.
- acceptance:
  - 10초 한국어 녹음이 텍스트로 변환되어 `input_type=VOICE` 메시지로 저장된다.
  - 답변 "듣기" 클릭 시 2초 내 재생이 시작된다.
  - 보이스 모드에서 재생 종료 후 자동으로 녹음이 시작되고, 끄기 전까지 반복된다.
  - 처리 후 `/tmp/audio`에 파일이 남지 않는다.
  - 마이크 권한 거부 시 안내 메시지가 뜨고 텍스트 입력은 계속 가능하다.

### M4 어드민
- api: `/admin/**` ROLE_ADMIN, persona CRUD, users 목록/상태, stats, rooms/messages 조회.
- web: `(admin)` 페이지 4종.
- acceptance:
  - 일반 사용자가 `/admin` 접근 시 403 또는 `/`로 리다이렉트.
  - 페르소나 변경 후 다음 메시지부터 새 시스템 프롬프트가 적용된다.
  - 정지된 회원은 로그인은 되지만 메시지 전송이 403.

### M5 NAS 배포 · PWA 검증
- DSM 리버스 프록시, `.env` 작성, OmniRoute 공급자/키 설정, 첫 배포, iOS/Android 홈화면 설치.
- acceptance:
  - `master` push 후 5분 내 NAS에서 새 이미지로 기동된다.
  - iOS 홈화면 PWA에서 소셜 로그인 왕복이 성공한다(또는 실패 시 D-번호로 대안 결정).
  - 오프라인 상태에서 앱 셸은 뜨고 "연결 없음" 안내가 나온다.
