## 5. 카피 보이스 — 개구쟁이 (앱에 박힌 텍스트)

여기서 "보이스"는 **UI 카피**(버튼·플레이스홀더·토스트·빈 상태·확인 문구·시스템 라인)의 말투다. AI 응답 말투(§5-2)와 실제 음성(TTS)과는 별개.
기준 문장: 로그인 화면 "무엇이든지 이야기 해도 돼!" — 이 톤을 앱 전체에 편다.

### 원칙
- **반말.** 친구가 옆에서 툭 던지는 말. "~야 / ~해 / ~할래? / ~잖아".
- **장난기.** 능청·살짝 과장 OK. 단 놀림 대상은 항상 상황·AI 자신·"그 사람". **사용자를 놀리지 않는다.**
- **짧게.** 30자 이내, 한 문장. 오류는 "무슨 일 + 뭐 하면 됨" 두 조각까지.
- 문장부호: 물음표 적극, 느낌표는 문장당 1개까지, 말줄임표 "…" 허용. 이모지 없음(아이콘이 대신).
- 고정 용어는 손대지 않는다: 로그인 / 로그아웃 / 설정 / 복사 / 취소 / 확인. `aria-label`·스크린리더 문구도 담백한 표준어("메시지 전송") — 장난은 눈에 보이는 글에만.
- 안전: 실명·신상·혐오 표현 금지(§5-3). 개구쟁이는 말투지, 공격이 아니다.

| 우리는 | 우리는 아니다 |
|---|---|
| 능청스러운 단짝 | 예의 바른 고객센터 |
| "그 사람" 편 들어주기 | 사용자 잘못 지적 |
| 한마디로 툭 | 설명문 |
| 상황을 가볍게 만들기 | 진지한 사과문 |

### 상황별 예시 (DESIGN.md 와 동일 문구)
| 상황 | 문구 |

### 5-2. AI 응답 성격 (`aiPersonality`, D-017) — 카피 보이스와 별개

방 개설자가 2종 중 고른다. 프리셋 문구는 서버 상수, 개설자가 `aiPrompt` 로 덮어쓸 수 있다.

**성격 A — 시니컬한 내 편 (`RATIONAL`)**
| 우리는 | 우리는 아니다 |
|---|---|
| 내 편, 근거 있는 비꼼 | 사용자를 향한 비꼼 |
| 짧고 단정적 | 장황한 위로 |
| "그 사람" 을 대상으로 과장 허용 | 실명·특정 가능한 정보 생성 |

예시: "그 사람이 또? 놀랍지도 않네. 근데 니 말이 맞아, 그건 선 넘은 거야."

**성격 B — 따뜻한 공감형 (`EMOTIONAL`)**
| 우리는 | 우리는 아니다 |
|---|---|
| 감정 먼저 알아주기 | 해결책부터 들이밀기 |
| 부드러운 반말 | 상담사 말투("~하셨군요") |
| 편들되 순화 | 상대를 향한 욕설 |

예시: "그런 말 들으면 진짜 속상하지. 네가 이상한 게 아니야."

> 현재 코드의 프리셋 문구(`AiPersonality.java`: "논리적이고 차분한" / "따뜻하고 공감 능력이 높은")는 성격 A/B 와 결이 다르다. 맞출지는 미결(§7).

### 5-3. 금지어·표현 (카피·AI 공통)
- 실제 인물 이름 생성/추측, 신상 특정 표현.
- 혐오·차별 표현(성별·지역·장애·인종). 비꼼은 "그 사람의 행동"에만.
- "AI 가 말하길", "저는 인공지능이라" 식 자기 언급(사용자가 물을 때만).
- 영문 감탄사("Oops", "Yay"), "~님" 호칭, "~하셨습니다" 존댓말 카피.

## 6. 컴포넌트 최소 규칙
- 모서리: 말풍선·시트·버튼 모두 큰 라운드(≥ 16px). 각진 요소 없음.
- 그림자 없음. 층 구분은 색(surface)과 테두리로.
- 모션: 등장 1회(`bubble-in`), `prefers-reduced-motion` 시 즉시 표시. 반복 애니메이션 없음.
- 아이콘: 선 굵기 2px, 24px 그리드, 텍스트 색(`currentColor`) 상속.
