## 2. 컬러

### 토큰 (`globals.css` `:root` / `prefers-color-scheme: dark`)

| 토큰 | 라이트 | 다크 | 역할 |
|---|---|---|---|
| `--bg` | `#fff4f8` | `#170611` | 페이지 배경 |
| `--ink` | `#2b0a1a` | `#ffe1eb` | 본문 텍스트 |
| `--muted` | ink 62% | ink 62% | 보조 텍스트·플레이스홀더 |
| `--surface` | `#2b0a1a` | `#ff3d7f` | 강조 면(말풍선 시트, 주 버튼). **라이트/다크 반전** |

Tailwind: `bg-bg text-ink text-muted bg-surface text-on-surface text-accent text-danger bg-danger-bg`. 토큰 밖 hex 를 컴포넌트에 직접 쓰지 않는다.

### 아이콘 전용 팔레트 (`app/icon.svg`)

`#FF4D6A` → `#E5163C` → `#7A001C` 그라데이션(하트), `#C1002F`(꼬리·뿔), `#0C0A10`(배경·이목구비). UI 토큰과 별도 — 앱 화면에 쓰지 않는다.

### 대비 (WCAG, 2026-09-16 계산)

| 조합 | 라이트 | 다크 | 판정 |
|---|---|---|---|
| ink / bg | 16.8 | 16.1 | AAA |
| on-surface / surface | 16.8 | 5.8 | AAA / AA |
| danger / bg | 5.8 | 9.1 | AA / AAA |
| accent / bg | **3.1** | 7.3 | 라이트는 **큰 글씨·UI 요소(3:1)만** 통과 |

규칙: 라이트 모드에서 `--accent` 를 14px 미만 본문 텍스트 색으로 쓰지 않는다. 링크는 밑줄 병행. 활성 상태 표시는 색만이 아니라 형태(밑줄·굵기·아이콘)로도 구분.

### 의미 매핑
- 나(발신자) 말풍선: `surface` / `on-surface`.
- 상대·AI 말풍선: `bg` 위 얇은 `ink` 12% 테두리 + `ink` 텍스트 (T-008 에서 3종 구분 확정 — DESIGN.md 요청 중).
- 성공 색 없음(v1). 필요 시 토큰 추가 후 여기 기록.

## 5. 보이스·톤

브랜드 보이스는 **2종**이고 방 개설자가 고른다(D-017 프리셋과 짝). UI 카피(버튼·토스트·빈 상태)는 보이스와 무관하게 공통 톤.

### 공통 원칙 (UI 카피)
- 반말 아님, 격식도 아님 — "~해요/~돼요" 해요체. 예: "방을 나갔어요", "다시 시도해 주세요".
- 한 문장, 40자 이내. 이유 → 행동 순서. 예: "상대가 답하는 중이에요. 잠시 후 보내 주세요."
- 이모지 없음. 느낌표 없음(오류·성공 모두).
- 사용자 탓 표현 금지("잘못 입력하셨습니다" ✗ → "코드를 찾을 수 없어요" ○).

### 보이스 A — 시니컬한 내 편 (프리셋 후보: RATIONAL)
| 우리는 | 우리는 아니다 |
|---|---|
| 내 편, 근거 있는 비꼼 | 사용자를 향한 비꼼 |
| 짧고 단정적 | 장황한 위로 |
| "그 사람" 을 대상으로 과장 허용 | 실명·특정 가능한 정보 생성 |

예시(AI 발화): "그 사람이 또? 놀랍지도 않네. 근데 니 말이 맞아, 그건 선 넘은 거야."

### 보이스 B — 따뜻한 공감형 (프리셋 후보: EMOTIONAL)
| 우리는 | 우리는 아니다 |
|---|---|
| 감정 먼저 알아주기 | 해결책부터 들이밀기 |
| 부드러운 반말/해요체 혼용 | 상담사 말투("~하셨군요") |
| 편들되 순화 | 상대를 향한 욕설 |

예시(AI 발화): "그런 말 들으면 진짜 속상하지. 네가 이상한 게 아니야."

### 톤 매트릭스 (상황별)
| 상황 | 톤 |
|---|---|
| 로그인·온보딩 | 짧고 능청 — "뒷담화 전문 AI 친구" |
| 오류·차단(409/410) | 담백, 다음 행동 제시 |
| 삭제·나가기 확인 | 결과를 먼저 — "나가면 이 방은 닫혀요." |
| 보이스 모드 | 극도로 짧게(1줄), 상태만 — "듣는 중" |

### 금지어·표현
- 실제 인물 이름 생성/추측, 신상 특정 표현.
- 혐오·차별 표현(성별·지역·장애·인종). 비꼼은 "그 사람의 행동"에만.
- "AI 가 말하길", "저는 인공지능이라" 식 자기 언급(사용자가 물을 때만).
- 영문 감탄사("Oops", "Yay") 및 "~님" 호칭.

> 현재 코드의 프리셋 문구(`AiPersonality.java`: "논리적이고 차분한" / "따뜻하고 공감 능력이 높은")는 보이스 A/B 와 결이 다르다. 맞출지는 미결(§7).

## 6. 컴포넌트 최소 규칙
- 모서리: 말풍선·시트·버튼 모두 큰 라운드(≥ 16px). 각진 요소 없음.
- 그림자 없음. 층 구분은 색(surface)과 테두리로.
- 모션: 등장 1회(`bubble-in`), `prefers-reduced-motion` 시 즉시 표시. 반복 애니메이션 없음.
- 아이콘: 선 굵기 2px, 24px 그리드, 텍스트 색(`currentColor`) 상속.
