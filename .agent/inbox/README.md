# inbox — 역할 간 요청/이슈 전달

> 파일 하나 = 받는 역할 하나. **보내는 쪽이 append**, 받는 쪽은 처리 후 항목에 `[처리됨 YYYY-MM-DD]`를 붙인다.
> 처리된 항목은 다음 사이클에 받는 쪽이 정리(삭제)한다.

| 파일 | 받는 역할 | 주로 오는 것 |
|---|---|---|
| to-ceo.md | CEO | 결정 요청(범위·우선순위·기술 갈림길), 미결 항목 |
| to-planner.md | 기획자 | acceptance 불명확, 요건 충돌, 범위 질문 |
| to-designer.md | 디자이너 | DESIGN.md에 없는 UI, 컴포넌트 명세 요청 |
| to-dev.md | 개발자 | QA FAIL 이슈, 계약 변경 알림 |
| to-qa.md | QA | REVIEW 전환 알림(검증 요청) |

## 항목 형식
```
### [보내는 역할 → 받는 역할] 제목 (T-xxx)
- 요청/이슈:
- 근거 파일:
- 원하는 결과:
- date:
```
