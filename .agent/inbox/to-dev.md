### [QA → 개발자] T-031 실측 FAIL — 2인 동시 AI 대화에서 AI 응답 실패 [처리됨 2026-09-19, 같은 T-031 안에서 수정]
- 증상: 두 사람이 `AI` 모드에서 거의 동시에 질문하면 **나중 질문의 답이 안 오고** 말풍선에 "시스템 오류. 다시 시도해줄래?".
  api 로그 `AI job failed room=10048 reply_to=2041: OmniRoute responded 400`, 상류(Gemini) 원문
  `[400]: Requests ending with a model turn are not supported.` (2041, 2044 두 번 재현)
- 원인: 방 10048 순서 = 2040 빵선이 질문 / **2041 상남자 질문** / 2042 빵선이에게 준 답. 빵선이의 잡이 먼저 끝나 2042 를
  저장했고, 그 뒤 상남자의 잡이 "최근 30개"를 읽으면서 2042(assistant)가 **마지막 턴**으로 들어갔다. Gemini 는 model 턴으로
  끝나는 요청을 거부한다. 같은 원인으로 AI 가 상대 질문에 답하는 혼선도 생긴다(잡이 자기 질문 이후 턴까지 봄).
  D-037 이전에도 가능한 구조였으나, 각자 AI 와 1:1 이 되면서 두 사람이 동시에 묻는 상황이 일상이 돼 드러났다.
- 수정: `findRecentForAiContext(roomId, upToMessageId, limit)` — 잡은 **자기 트리거 메시지까지만**(`id <= upToMessageId`) 읽는다.
  이러면 마지막 턴은 항상 트리거 USER 메시지이고, 답도 물어본 사람 것으로 고정된다. 테스트 +1(회귀), api 308 통과.
- 재검증 필요: 실측 (1) 두 사람이 연달아 질문 → 양쪽 각자 답을 받는다. (5) AI 가 엉뚱한 사람에게 답하지 않는다.
