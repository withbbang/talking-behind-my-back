## 버그 상세

### B-1 [P1][iOS] 드로어 안 메뉴 항목이 전부 무반응
- 재현 (iPhone 시뮬레이터 Safari, 모바일 폭)
  1. 방 화면 → 우상단 햄버거 → 드로어 열림
  2. 하단 프로필 버튼 "QA봇A" → 메뉴 "설정 / 로그아웃" 뜸
  3. "설정" 탭 → **메뉴만 닫히고 설정 시트가 안 뜸**(2회 재현). "로그아웃" 도 동일하게 무반응.
  4. 방 항목 "…" → "제목 수정" 탭 → 역시 메뉴만 닫히고 인라인 입력이 안 나옴.
- 같은 동작을 Android Chrome 에서 하면 설정 시트·제목 수정·로그아웃 모두 정상.
- 영향: 모바일 iOS 에서 설정 시트로만 갈 수 있는 기능 전부 막힘 — **친구 초대(QR/링크), 모드 전환, AI 성격, 테마, 로그아웃, 제목 수정**. 나가기도 같은 메뉴라 동일할 것으로 보임(이번엔 미확인).
- 원인 추정: `components/ui/useMenu.ts` 의 `onBlur` — `relatedTarget` 이 null 이 아니고 메뉴 밖이면 닫는다.
  iOS WebKit 은 버튼 탭 시 버튼 대신 가장 가까운 focusable 조상으로 포커스를 옮기는데, 드로어 컨테이너가
  `tabIndex={-1}`(`ChatShell.tsx` 드로어 `role="dialog"`)라 `relatedTarget` = 드로어 → 메뉴가 click 전에 언마운트된다.
  T-032 교훈(macOS Safari, `relatedTarget: null`)은 데스크톱 사이드바(드로어 아님)에서만 검증돼 이 경로를 못 잡았다.
  드로어 `ref={(el) => el?.focus()}` 가 인라인 콜백이라 ChatShell 재렌더마다 드로어로 포커스를 다시 가져가는 것도 같은 결과를 낼 수 있다.
- 기대: 메뉴 항목 탭 시 해당 동작 실행(DESIGN.md#2 프로필 메뉴, 방 … 메뉴).

### B-2 [P1] 보이스 모드 60초 상한 → 항상 "시스템 오류"
- 재현 (iOS 보이스 모드, 마이크 허용 후 아무 말 안 함)
  1. 컴포저 "음성" → 오버레이 → 권한 허용 → 녹음 0:00 → 60초 대기
  2. 60초에 자동 종료 → 카드 "시스템 오류. 다시 시도해줄래?"
- nginx: `POST /api/speech/stt 400` (09:00:03). DESIGN.md#7 기대는 토스트 "60초까지만 들을 수 있어!" 후 받아적기 진행.
- 원인(코드 확인):
  - 클라이언트 `useRecorder.ts` 는 `setTimeout(…, maxMs=60_000)` 으로 멈추고, `durationMs = Date.now() - startedAt` 을 **stop 이벤트 시점**에 잰다 → 항상 60,000 초과(수~수십 ms).
  - 서버 `SpeechService.stt` 는 `clientDurationMs > maxAudioMs(60000)` 이면 `AUDIO_TOO_LONG`. 공급자 보고 길이도 같은 비교.
  - 즉 "상한에 닿아 자동 종료된 녹음"이 서버 상한 검사에 항상 걸린다. 컴포저 마이크도 같은 `maxMs` 를 쓰면 동일할 것.
- 테스트 공백: 단위 테스트가 가짜 타이머로 정확히 60,000 을 넣으면 통과한다. 경계값(60,001~) 케이스 필요.

### B-3 [P2] 무음 녹음이 "Thank you." 로 전사돼 전송됨
- 재현 (Android Chrome, 컴포저 마이크, 에뮬레이터 마이크 = 무음)
  1. 마이크 → 권한 허용 → "듣는 중 0:05" → ✓
  2. `POST /api/speech/stt 200` → 내 말풍선 **"Thank you."** 가 VOICE 로 전송 → AI 가 영어로 "You're welcome…" 응답
- DESIGN.md#7: "STT 결과가 비면 토스트 '아무 말도 안 들렸는데?'". Whisper 는 무음에 "Thank you." 같은 환각을 자주 낸다 → 빈 결과로 오지 않아 이 분기를 못 탄다.
- 영향: 사용자가 말하지 않은 문장이 대화·LLM 컨텍스트·사용량에 남는다. 언어 자동 선택(D-042)도 영어로 틀어진다.
- 제안: `verbose_json` 의 `no_speech_prob`/세그먼트 정보로 거르거나, 클라이언트 VAD 가 "발화 없음"이면 STT 를 호출하지 않기(보이스 모드 VAD 는 이미 `spoke` 를 안다).

### B-4 [P2] 첫 메시지 자동 제목이 비공개 메시지를 노출할 수 있음
- 관찰: 방장 B 가 만든 "새 대화" 방에 A 가 입장 후 먼저 보낸 "안녕 B, 나 A야 (iOS)" 가 **방 제목**이 됨(양쪽 헤더·목록).
- 코드: `MessageService.java:91` — `messageCount == 0 && title == "새 대화"` 면 보낸 사람·모드와 무관하게 `autoTitle(content)`.
- 문제 시나리오(코드상 확정, 실측은 유저끼리 모드에서만 함): 방장이 메시지 없이 초대 → 참여자가 **AI 모드**로 먼저 질문 →
  그 질문(상대에게 비공개, D-037)이 제목이 되어 방장에게 보인다. 참여자가 방 제목을 정하는 것도 "제목은 개설자만"(API.md PATCH 규칙)과 어긋난다.
- 제안: 개설자의 메시지일 때만 자동 제목(또는 개설자의 AI 모드 메시지만). 결정 필요 → to-ceo 후보.

### B-5 [P2] 없는 방 SSE 가 500 으로 무한 재연결
- 재현: 로그인 상태로 `/rooms/99999999` 열기
- 화면: "그런 방 없는데?" (정상) / 헤더 제목은 "…" 로 남음
- nginx: `GET /api/rooms/99999999 404` 후 `GET /api/rooms/99999999/events 500` 이 **약 8초 간격으로 계속**(탭을 떠나도 백그라운드 탭에서 지속)
- api 로그: 매번 `Servlet.service() … threw exception [… BusinessException: 채팅방을 찾을 수 없습니다.]` ERROR + 전체 스택
  (`MessageController.events:65`). SSE 요청이라 `GlobalExceptionHandler` 의 JSON 응답을 못 써서 500 으로 새는 것으로 보임 — API.md 계약은 "비멤버 404".
- 영향: 로그 노이즈(운영 NAS), 불필요한 요청 루프. 고아방에서 나간 뒤 남은 탭 등 실제로도 생길 수 있음.
- 제안: 서버 — events 에서 멤버 검사를 SSE 시작 전 404 로 확실히 반환. 클라이언트 — 방 조회가 404/410 이면 SSE 를 열지 않고, 4xx 면 재연결 중단.

### B-6 [P3] 드로어 안 확인 다이얼로그가 중앙이 아님
- 재현 (Android): 드로어 → 방 "…" → 나가기 → "나가면 이 방은 끝이야. 진짜 나갈거야?"
- 다이얼로그가 화면 중앙이 아니라 **드로어(우측 300px) 안에 폭 ~190px** 로 뜸. DESIGN.md 는 폭 320 모달.
- 원인 추정: `ConfirmDialog` 가 포털 없이 `fixed inset-0` 인데 드로어에 `bubble-in`(transform) 애니메이션이 걸려 fixed 기준(containing block)이 드로어가 됨. 같은 다이얼로그를 방 화면에서 띄운 고아방 모달은 정상 중앙.
- 제안: 다이얼로그/시트는 `createPortal(document.body)`.

### B-7 [P3] 드로어가 저절로 다시 열림
- 재현 (iOS): 방 X 에서 드로어 열기 → 목록의 다른 방 Y 탭(드로어 닫히며 이동) → Y 에서 고아방 모달 "나가기" → X 로 돌아옴 → **드로어가 열린 채로 나타남**
- 원인(코드): `ChatShell` 이 `openPath === pathname` 으로 열림을 판정하고, 경로가 바뀌어도 `openPath` 를 비우지 않는다 → 같은 경로로 돌아오면 다시 true.

### B-8 [P3] 시스템 라인이 휘발 + 두 사람 타임라인 불일치
- 실시간으로 받은 "QA봇A 등장!", "유저끼리 대화 가능!", "AI랑 대화 가능!" 이 **새로고침/재접속하면 사라짐**(클라이언트 `notices` 만, API 에 저장 없음).
- 입장한 A 본인 화면에는 "QA봇A 등장!" 이 처음부터 없음(빈 상태 "오늘은 누가 짜증나게 했어?" 표시) — 방장 화면과 다름.
- 모드 전환 라인이 사라지면 "왜 상대 말풍선이 이 구간에만 있는지"(D-037 가시성) 맥락이 없어진다. 스펙 위반은 아님 → 저장 여부는 결정 사항.

## 관찰·개선 제안 (버그 아님 또는 판단 필요)
- **O-1** 기본 성격(차분한 편) AI 답이 존댓말·딱딱함 — "QA 테스트 메시지를 정상적으로 수신했습니다." 브랜드("뒷담 친구", 반말 카피)와 톤 차이. 프롬프트 문제라면 기획 판단.

- **O-5** 방 목록 "제목 수정" 인라인 입력에서 Chrome 자동완성 바(비밀번호/카드/주소)가 뜸 → `autoComplete="off"` 검토.
