# DESIGN — 화면 설계

> **Write: 디자이너 | Read: 개발자, QA**
> TL;DR: 화면 5종(로그인 / 채팅 셸 / 채팅방 / 보이스 모드 / 어드민). 모바일 우선(PWA), 데스크톱은 2단.
> 이 파일은 골격 상태 — 디자이너가 톤·컬러·컴포넌트 명세를 채운다. 개발자는 여기 없는 UI를 임의로 만들지 않고 inbox/to-designer.md로 요청.

## 원칙
- 모바일 우선. 기준 뷰포트 390×844(iPhone), 데스크톱 ≥1024에서 사이드바 고정.
- 입력창은 항상 하단 고정(키보드 올라와도 가려지지 않게 `100dvh` + safe-area).
- 스트리밍 중에도 레이아웃이 튀지 않도록 말풍선은 아래로만 자란다.
- 접근성: 모든 버튼 `aria-label`, 스트리밍 말풍선 `aria-live="polite"`, 포커스 링 유지.
- 다크/라이트: v1은 시스템 설정 따라감(수동 토글 없음).

## 화면

### 1. 로그인 `/login`
- 중앙 로고/한 줄 소개 + 소셜 버튼 3개(세로). 각 공급자 브랜드 가이드 준수(색·아이콘).
- 하단: 이용약관/개인정보 링크(텍스트).
- 오류(`?error=`) 시 상단 인라인 알림.

### 2. 채팅 셸 (`(chat)/layout.tsx`)
- 모바일: 상단 바(햄버거 · 방 제목 · 보이스 모드 토글). 햄버거 → 사이드바 드로어.
- 데스크톱: 좌측 사이드바 280px 고정 + 메인.
- 사이드바: "새 대화" 버튼(→ `/`), 방 목록(제목 1줄 말줄임 + 상대 시간), 길게 누르기/… 메뉴(제목 수정·삭제), 하단 프로필+로그아웃.

### 3. 채팅방 `/rooms/[id]` 및 draft `/`
- 메시지 목록: USER 우측/ASSISTANT 좌측. VOICE 입력 메시지는 작은 마이크 아이콘 배지.
- ASSISTANT 말풍선 하단: 듣기(스피커) 버튼, 재생 중이면 정지 아이콘으로.
- 스트리밍 중: 커서 깜빡임 + "생각 중…" 스켈레톤(첫 delta 전).
- 하단 입력창: 텍스트 영역(자동 높이, 최대 5줄) · 마이크 버튼 · 전송 버튼. 전송 중엔 전송 버튼 → 정지 버튼(요청 취소).
- draft(`/`): 목록 비어 있을 때 중앙 안내 문구 + 예시 프롬프트 칩 3개(탭하면 입력창에 채움).
- 오류: 409 → 하단 토스트 "답변이 끝난 뒤 보내주세요". 502 → 말풍선 자리에 "다시 시도" 버튼.

### 4. 보이스 모드 (오버레이)
- 상단 바 토글로 진입. 전체 화면 오버레이, 채팅 목록은 뒤에 흐릿하게.
- 중앙 큰 원(상태별 애니메이션):
  - `recording` — 파형/펄스, "듣고 있어요"
  - `transcribing` — 스피너, "변환 중"
  - `streaming` — 텍스트 미리보기(응답 델타), "답변 중"
  - `speaking` — 원이 음성에 맞춰 진동, "말하는 중"
- 하단: "중단"(현재 단계 취소 후 recording으로) · "끄기"(오버레이 닫기).
- 권한 거부: 원 대신 안내 카드 + "설정 열기" 안내.
- 변환된 사용자 발화와 응답은 오버레이 닫은 뒤 채팅 목록에 그대로 남아 있어야 한다.

### 5. 어드민 `/admin`
- 좌측 네비(대시보드 · 회원 · 대화 · 페르소나). 데스크톱 전용 레이아웃(모바일 최적화 안 함).
- 대시보드: 숫자 카드 5개(회원·방·메시지·오늘 토큰·30일 토큰) + 최근 7일 메시지 수 막대.
- 회원: 테이블(닉네임·공급자·상태·가입일·마지막 로그인) + 검색 + 상태 토글.
- 대화: 회원 선택 → 방 목록 → 메시지 읽기 전용 뷰.
- 페르소나: 목록 + 편집 폼(이름·시스템 프롬프트 textarea·글자 수) + 활성화 버튼(확인 다이얼로그).
